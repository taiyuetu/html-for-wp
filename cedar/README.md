# 冷杉制冷 · 工业制冷设备企业站模板

一套可直接双击打开的静态企业官网模板，9 个页面，无框架、无构建依赖、无外链资源。
结构范式参考工作目录中的三个企业站模板（`k759` / `k773` / `k778`），视觉重做为**冷钢工业 + 工程图纸**方向。

演示品牌「冷杉制冷 / CEDAR COOL」与企业信息、项目数据均为虚构示例，仅用于模板展示。

## 二、设计定调

- **受众**：冷链、食品、医药、数据中心、化工行业的工程负责人与采购。
- **方向**：工业实用（Industrial / utilitarian）。信息密度可控，靠 1px 发丝线与模块网格建立秩序，不靠阴影和圆角。
- **字体**：`Anton`（拉丁大数字 / 展示）+ `IBM Plex Mono`（参数、编号、标签）+ 系统中文字体（PingFang SC / 思源黑体 / 微软雅黑）。
- **颜色**：冷纸 `#EEEDE7`（60%）+ 冷钢 `#0C1114`（30%）+ 冷媒青 `#0A6B74` / 亮青 `#35DFC6`（10%，仅用于动作与关键数据）。
- **记忆点**：全站没有一张位图——产品、工厂、案例、结构图全部是手绘 SVG 线稿，配合右侧温度标尺、等宽参数与图纸编号（`DWG` / `Fig.` / `Section A-A`）。

## 四、目录结构

```
cedar/
├── index.html                    ← 构建产物，可直接打开
├── products/ solutions/ case/ about/ news/ contact/
├── sitemap.xml
├── assets/
│   ├── css/
│   │   ├── fonts.css             ← 字体内联（base64，离线可用）
│   │   ├── tokens.css            ← 颜色 / 字阶 / 间距 / 动效令牌
│   │   ├── base.css              ← 重置、排版基线、可访问性、入场动画
│   │   ├── components.css        ← 头部、Hero、卡片、表格、表单、页脚等
│   │   └── pages.css             ← 页面级布局（分栏、时间轴、地图、正文）
│   ├── js/main.js                ← 原生 JS 交互，无依赖
│   ├── fonts/                    ← 原始 woff2（已内联，可留作换外链用）
│   └── img/                      ← favicon.svg、qr.svg（占位二维码）
└── _build/
    ├── build.py                  ← 装配脚本：注入页头页脚 + 路径改写 + 生成 sitemap
    ├── pages/*.html              ← 各页 <main> 正文（唯一需要日常编辑的地方）
    └── test_ui.py                ← 可选的 Playwright 自检脚本
```

## 五、运行与重建

```bash
# 直接浏览：双击 index.html 即可（字体已内联，file:// 下也正常）

# 或起本地服务（推荐，便于相对路径与无缓存调试）
cd cedar && python -m http.server 8080     # → http://127.0.0.1:8080/

# 修改 _build/pages/*.html 或 _build/build.py 后重新生成页面
python _build/build.py
```

> 构建脚本只做三件事：套用 `<head>` / 页头（含 Mega 菜单）/ 抽屉 / 页脚 / 悬浮条，把正文里 `href="/xxx"` 改写为相对路径，生成 `sitemap.xml` 与占位二维码。产物是纯静态文件，可以脱离脚本直接改 HTML。

## 七、动效

- **一次编排的入场**：首屏眉标 → 标题 → 正文 → 按钮，错峰 60–300ms；首屏线稿用 `stroke-dashoffset` 描边生长。
- **滚动触发**：`IntersectionObserver` 控制 `[data-reveal]`，同组元素自动错峰 80ms，只动 `opacity` / `transform`。
- **轮播**：7s 自动切换，进度条与 `01 / 03` 计数同步；鼠标悬停、键盘聚焦、切到后台都会暂停；支持左右方向键与触摸滑动。
- **跑马灯**：资质条 CSS 无限滚动，悬停暂停。
- **悬停反馈**：按钮自下而上擦除填充、卡片线稿放大并转强调色、能力行整行反色、新闻日期变青。
- **降级**：全部动效包在 `prefers-reduced-motion` 下关闭，内容直接可见（已用 Playwright 验证）。

## 八、替换指南

1. **品牌与联系方式**：`_build/build.py` 中的 `SITE_NAME`、`TEL`、页脚/抽屉文案；各页正文里的电话与地址。
2. **产品**：改 `_build/pages/products.html` 与 `product-detail.html`；`.pcard__art` 内的 SVG 可整段替换为 `<img src="..." alt="...">`，`.pcard__art` 的图纸网格背景会保留。
3. **图片**：模板刻意不含位图。若要改用实拍图，建议在 `.pcard__art`、`.case__art`、`.blueprint` 内放 `<img>`，并保持 4:3 / 16:8.4 比例，避免布局跳动。
4. **表单接后端**：`assets/js/main.js` 中「9. 表单校验」的 `setTimeout` 模拟提交处，替换为 `fetch('/api/inquiry', {...})`；成功/失败态复用 `.form__success` 与 `.field.is-invalid`。
5. **备案号**：页脚 `苏ICP备00000000号-1（模板占位）` 换成真实备案号；二维码 `assets/img/qr.svg` 换成真实微信码。
6. **导航结构**：改 `_build/build.py` 的 `NAV_ITEMS`、`PRODUCTS_MEGA_*`，重新构建即可，9 个页面同步更新。

## 九、自检结果

**自动化检查（`_build/test_ui.py`，Playwright + 本机 Chrome，57 项全部通过）**

- 375 / 768 / 1024 / 1440px 四档 × 9 个页面：无横向溢出、无控制台报错。
- Mega 菜单悬停展开、`aria-expanded` 同步、Esc 关闭；移动抽屉开合、滚动锁定、二级菜单展开。
- 轮播切屏与计数同步；产品筛选（CO₂ → 2 个、全部 → 9 个）；产品 4 视图切换。
- 表单空提交产生 3+ 个 `is-invalid` 且不显示成功态，填写完整后显示成功态；折叠面板同组互斥。
- `prefers-reduced-motion: reduce` 下所有 `[data-reveal]` 直接可见，无脚本错误。

**对比度实测**

| 组合 | 比值 |
|---|---|
| `#12181C` on `#EEEDE7` | 15.3:1 |
| `#5C666C` on `#EEEDE7` | 5.0:1 |
| `#0A6B74` on `#EEEDE7` | 5.3:1 |

**反 AI 味清单**：展示字未使用 Inter / Roboto / system-ui；无白底紫渐变；首屏不是「居中标题 + 两个按钮 + 三张卡」；卡片非千篇一律圆角阴影（全站 0 圆角、0 卡片阴影）；文案不含「赋能 / 一站式 / 新一代」；每个页面都有可描述的记忆点（温度标尺、图纸编号、`−60℃` 水印）。

## 十、已知取舍

- 全站无位图，产品与案例以线稿示意表达；替换为实拍图后视觉会更"企业站"，但会失去图纸记忆点，建议两者混用（首屏与卡片保持线稿）。
- 表单为前端演示，未接后端；新闻分页为静态占位。
- 字体 Anton、IBM Plex Mono 均为 SIL Open Font License，可商用；中文字体走系统字体，不引入 CJK webfont（体积与首屏考虑）。
- 仅支持现代浏览器（Chrome / Edge / Safari 15+ / Firefox 90+），未提供 IE 兼容层；CSS 使用 `clamp()`、`aspect-ratio`、`grid`、`mask-image`。
