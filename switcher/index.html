02

System Philosophy

One platform logic. Every wall condition.

The insert is the product. The plate is the architecture.

Every AXIOM system is built on one mechanical standard: 55 mm fixing centres, a Ø 60 mm machine back box and a single-screw carrier. Frames, rockers, inserts and plates are interchangeable across the complete platform — a specification written for one wall type holds for every other.

Function lives in the insert, not the plate. Switch, dimmer, socket-outlet, data and control modules share one carrier geometry, so layouts can be re-planned after installation without touching the wall finish.

06

Smart Control & System Integration

Control architecture on the bus, not the cloud.

Local-first logic. Open protocols. No gateway dependency.

AXIS TOUCH stations and AX-BUS actuators form a local control topology — scenes, blind and HVAC logic run on the line, with an optional KNX gateway for higher-level systems.

  • Local-first logic. Scenes execute on the line bus; no cloud dependency for core functions.
  • Open protocols. KNX TP, DALI gateway, Modbus TCP uplink for BMS integration.
  • Re-addressable. Every point is re-configured on site — plates are never re-commissioned.
