# 鼎轴底盘 · 汽车底盘件制造企业站模板

一套可直接双击打开的静态企业官网模板，9 个页面，无框架、无构建依赖、无外链资源。
结构范式沿用同一工作目录里三个企业站模板（`k759` / `k773` / `k778`）的信息骨架，
视觉另起一套方向：**重工业编辑体（Industrial editorial）**。

演示品牌「鼎轴底盘 / DINGZHOU CHASSIS」及企业信息、项目数据均为虚构示例。

---

## 一、结构沿用与视觉差异

**沿用的骨架**（采购方熟悉的浏览路径）：顶栏 → 主导航 + 巨型菜单 → 首屏 → 资质带 →
关于 + 数字 → 产品矩阵 → 工艺能力 → 配套项目 → 新闻 → 客户名录 → CTA → 页脚 → 悬浮联系。

## 二、设计定调

- **受众**：主机厂底盘科、采购与 SQE；售后改装渠道。
- **方向**：重工业编辑体。用宋体大字、橙色规则线、竖排标号与图纸编号，做出「机械图纸 + 工业杂志」的混合感。
- **字体**：`Noto Serif SC 900`（中文标题，按实际用字生成子集）+ `Archivo Black`（拉丁字/数字）+ `JetBrains Mono`（参数、编号、标签）+ 系统中文无衬线（正文）。
- **颜色**：骨白（主导表面）+ 石墨（产品区与页脚）+ 熔橙（色带、按钮、关键数据，单页不超过 10%）。
- **记忆点**：**受力路径**。首屏右侧是可切换的轴测零件图，橙色箭头表示载荷方向；全站章节用 `PLATE 01/02…` 标号，像一本装订好的图纸册。

## 四、目录结构

```
dingzhou/
├── index.html                     ← 构建产物，可直接双击打开
├── products/ capability/ case/ about/ news/ contact/
├── sitemap.xml
├── assets/
│   ├── css/
│   │   ├── fonts.css              ← 字体内联（base64，离线可用，含中文字集）
│   │   ├── tokens.css             ← 颜色 / 字阶 / 间距 / 动效令牌
│   │   ├── base.css               ← 重置、宋体标题、可访问性、入场
│   │   ├── components.css         ← 头部、首屏、图版、卡片、工序、表格、表单、页脚
│   │   └── pages.css              ← 页面级布局（关于、详情、文章、联系、流程）
│   ├── js/main.js                 ← 原生 JS 交互
│   ├── fonts/                     ← 原始 woff2（供换外链时使用）
│   └── img/                       ← favicon.svg、qr.svg（占位二维码）
└── _build/
    ├── build.py                   ← 装配：注入页头页脚 + 路径改写 + sitemap + 占位二维码
    ├── build_fonts.py             ← 按页面实际标题用字生成中文字体子集并内联
    ├── get_fonts.py               ← 拉取 Archivo Black / JetBrains Mono 拉丁子集
    ├── test_ui.py                 ← Playwright 自检（61 项）
    └── pages/*.html               ← 各页 <main> 正文
```

## 五、运行与重建

```bash
# 直接浏览
双击 index.html（字体与样式全部内联，file:// 下正常）

# 本地服务（推荐调试）
cd dingzhou && python -m http.server 8080     # → http://127.0.0.1:8080/

# 改完正文后重建
python _build/build.py
python _build/build_fonts.py     # 若新增了标题用字，重跑一次以补齐中文子集
```

> `build_fonts.py` 会扫描所有页面的 `h1/h2/h3/图注标题`，提取其中的汉字，向 Google Fonts 请求
> 按字子集（分批，避免 URL 过长），再以 base64 内联进 `fonts.css`。新增标题文字后如果不重跑，
> 新字会自动回退到系统宋体（`Songti SC` / `SimSun`），不会乱码。

## 六、设计令牌（摘要）

| 类别 | 令牌 | 值 |
|---|---|---|
| 表面 | `--bone` / `--graphite` | `#E8E3D9` / `#17171A` |
| 文本 | `--text` / `--muted` | `#1B1B1E`（13.4:1）/ `#5F5B54`（5.3:1） |
| 强调 | `--accent` / `--band` / `--accent-bright` | `#A83211`（5.3:1）/ `#C03A12` / `#FF6A33`（6.3:1） |
| 发丝线 | `--line` / `--line-strong` | 16% / 36% 石墨 |
| 字阶 | `--fs-display` … `--fs-mono` | `clamp(44–96px)` … `11px` |
| 布局 | `--container` / `--gutter` / `--rail` | `1400px` / `clamp(20–52px)` / `78px` |
| 动效 | `--ease-out` | `cubic-bezier(.16,1,.3,1)`；120 / 180 / 320 / 640 / 1000ms |

中文排版：正文行高 1.8–1.95；宋体大标题行高 1.08–1.16、字距 −0.012em；标题宽度用 `em`
（`ch` 对汉字只有半个字宽）；长标题手动断行，避免「覆盖」这类词被拆到两行。

## 七、交互与动效

- **首屏零件切换**：6 个零件标签联动右侧轴测图、材料/公差/疲劳/重量四项参数与图注；切换时图版先淡出 170ms 再换图。
- **首屏入场**：标题三行遮罩上移（0 / 120 / 220ms），随后正文与按钮错峰出现。
- **滚动入场**：`IntersectionObserver` + `[data-reveal]`，同组自动错峰 90ms，只动 `opacity/transform`。
- **悬停**：工序行整行从左侧擦入橙色并反色；产品卡放大线稿并把件号换成亮橙；按钮左侧擦入实色。
- **跑马灯**：橙带资质无限滚动，悬停暂停。
- **降级**：`prefers-reduced-motion: reduce` 下关闭全部动效与遮罩，内容直接可见（已测）。

## 八、替换指南

1. **品牌与联系方式**：`_build/build.py` 里的 `SITE`、`TEL`、页脚/抽屉文案；各页正文中的地址与电话。
2. **产品**：改 `_build/pages/products.html` 与 `product-detail.html`；`.part__art` 里的 SVG 可整段换成 `<img>`，卡片底色与件号样式会保留。
3. **图片**：模板不含位图，全部为工程线稿。若要放实拍件照，建议替换 `.part__art` 内部，并保持 4:3；详情页主图保持 4:3.2。
4. **表单接后端**：`assets/js/main.js` 第 9 节里的 `setTimeout` 模拟提交，替换为 `fetch('/api/inquiry', …)` 即可，错误/成功态复用现有样式。
5. **新增标题文字**：改完页面后执行 `python _build/build_fonts.py`，否则新字可能回退到系统宋体。
6. **备案号与二维码**：页脚 `苏ICP备00000000号-1（模板占位）`、`assets/img/qr.svg` 换成真实内容。
7. **导航结构**：改 `build.py` 的 `NAV` / `PARTS` / `CAPS`，重新构建即同步全部 9 页。

## 九、自检结果

**自动化检查（`_build/test_ui.py`，Playwright + 本机 Chrome，61 项全部通过）**

- 375 / 768 / 1024 / 1440px × 9 页：无横向溢出、无控制台报错。
- 巨型菜单悬停展开与 Esc 关闭；移动抽屉开合、滚动锁定、二级菜单、焦点约束。
- 首屏零件切换：视图显隐、参数联动、`aria-selected` 同步。
- 产品筛选（球头 → 2 个、全部 → 9 个）、筛掉收口卡与恢复。
- 详情页 4 视图切换；表单空提交产生 3+ 个 `is-invalid`，填写完整后显示成功态；折叠面板同组互斥。
- 工序行 hover 填充层生效（已修复负 z-index 被父级背景遮挡的问题）。
- `prefers-reduced-motion: reduce`：内容直接可见、首屏标题不依赖动画。

## 十、已知取舍

- 无位图，零件与项目以轴测线稿表达；实拍与线稿混用时建议首屏与卡片保持线稿，文章内页放实拍。
- 中文字体是「按标题用字」的子集，约 185 KB（含 3 个分片）；新增标题字需重跑字体脚本，或接受系统宋体回退。
- 表单为前端演示；新闻分页为静态占位；项目与客户均为虚构示例。
- 仅支持现代浏览器（Chrome / Edge / Safari 15+ / Firefox 90+），未做 IE 兼容。
