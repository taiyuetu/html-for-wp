# HTML 静态站点合集（WordPress 建站素材）

五套纯静态中文企业官网模板 + 一套英文品牌落地页，均为**无框架、无构建、无后端**的裸 HTML/CSS/JS，
可直接双击 `index.html` 浏览，也可整目录上传到 WordPress 站点或任意静态托管。

| `dingzhou/` | 鼎轴底盘｜控制臂·转向节·副车架 | 9 | 原创重制 | 重工业编辑体风格，演示数据为虚构 |
| `k759/` | 机电设备模板（产品带视频 / 三级栏目） | 46 | [镜像](https://yanshi.92wailian.com/k759/) | 原站 PbootCMS 模板，链接已改写为相对路径 |

各目录内另有独立 `README.md`，记录该站的目录结构、路由映射与抓取缺口。

## 打开方式

```bash
# 直接双击各目录下的 index.html 即可，无需服务端
# 或起一个本地静态服务：
cd k778 && python -m http.server 8765   # http://127.0.0.1:8765/
```

## 关于镜像站

`k759` / `k773` / `k778` 由原站抓取而来：PbootCMS 的 `?栏目/ID.html` 伪静态路由已映射为
`目录/ID.html` 的静态结构，站内链接全部重写为相对路径，可离线浏览。
少数资源在原站即返回 404（模板作者漏传），本地按原样保留，详见各目录 README。
